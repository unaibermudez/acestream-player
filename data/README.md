# data/

Carpeta montada (solo lectura) en el contenedor `web` y servida en `/data/`.

- `catalog.json`: catálogo de canales. Si existe, la app lo carga automáticamente en todos los
  dispositivos. Para actualizarlo, sustitúyelo y recarga la página.

El contenido de esta carpeta no se versiona (ver `.gitignore`).
